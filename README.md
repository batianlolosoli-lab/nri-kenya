## How to deploy

1. Unzip this package.
2. Copy all HTML files, the `documents/` folder, and updated `assets/styles.css` + `assets/site.js` into your existing project.
3. Keep your existing media: `hero-video-web.mp4`, community images, logo.
4. Deploy to Netlify (drag folder or git push).

Links use relative paths (`index.html`, `documents/...`) so the package works locally and as a static site. On Netlify with pretty URLs you can adjust if preferred.
